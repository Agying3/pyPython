# 快速开始

## 环境要求

- **Python 3.10+**（开发环境是 3.13.12）
- **Tkinter**（Python 自带，Windows 官方安装包默认含）
- **无第三方依赖**——`pip install` 一个包都不用装

## 跑解释器

不需要 IDE，解释器本体可以单独用：

```
python pypython.py
```

`main()` 里有**四个测试用例**，会依次打印：

1. **语法上能过**：一份用上全部语法的示例源码 + 执行结果
2. **性能上拉垮**：与 CPython 对比，两个基线都报
3. **抽象上拉满**：一次 `1+1` 到底绕了多少路，完整泬账本
4. **三值逻辑**：六个演示，含真值表、静默观测、溯源——**账本原文照抄**

想自己跑一段源码，用 `evaluate_source`：

```python
import pypython

report = pypython.evaluate_source('a「1」\n$(a + 1)\n')
print(report["output"])   # ['2 ⟨TRUE⟩ 0b10']
```

返回的字典里有输出、token 数、语句数、泬数、账本明细、真值密室审问次数等。

## 跑 IDE

项目里有**两套 IDE**，都能用，互不冲突：

```
python pypython_idle_start.py                开一个空白编辑器
python pypython_idle_start.py 你的文件.pypy   打开指定文件
python -m pypython_idle                       等价，需要先 cd 到项目根
```

**推荐第一条**——它不要求当前目录在哪，直接跑就行。

启动后应该看到：

- 一个**空白**编辑器窗口，标题 `untitled (pyPython)`
- 菜单栏跟 IDLE 一样
- **没有**输出面板（按 F5 跑完代码之后才会出现）

想看点东西跑起来：

```
python pypython_idle_start.py examples\hello.pypy
```

→ 两套 IDE 的区别见 [IDE 使用](IDE-使用)

## 跑测试

```
python tests/run_all.py
```

11 个脚本，**全部通过**才算成功。每个脚本都是独立进程
（IDE 那几个要开 Tk 窗口，进程内反复建销毁 root 会互相干扰）。

单个跑也行：

```
python tests/test_v4_three_valued.py      三值逻辑，81 项
python tests/test_keyword_sync.py         关键字表同步
```

## 写自己的第一个程序

新建 `hello.pypy`：

```
# 注释用 #
名字「pyPython」
$(名字)

# 三值逻辑
约到了「未知」
$(约到了 and 1)     # MAYBE ⟨MAYBE⟩——不确定的一侧压不过去
$(约到了 and 0)     # 0 ⟨FALSE⟩ 0b0 ——确定的假能压过未知

if 约到了
    $("走进 then")
else
    $("走进 else")

# 上面这个 if 两个分支都不会执行！只记一笔账。
# 因为条件是「未知」，语言不替你猜。
```

然后：

```
python pypython_idle_start.py hello.pypy
```

按 F5 运行。

```

```

## 常见问题

**Q：为什么 `$(1+1)` 输出 `2 ⟨TRUE⟩ 0b10` 而不是 `2`？**

这是设计目标。见 [输出格式](输出格式)。

**Q：为什么 `~` 和 `·` 打反了不报错？**

因为两个都是合法运算符，只是意思相反。这是已知设计，见
[已知限制](已知限制)。

**Q：`if` 条件写了个变量，怎么什么都没执行？**

那个变量多半是 `未知`。这是三值逻辑的静默观测——
两个分支都不执行，只往账本记一笔。**去输出里找那行「炑：静默观测已触发」**。
见 [三值逻辑](三值逻辑)。

**Q：启动和退出时报 `warning: callback failed in WindowList`？**

**不是本项目引入的。** 已用**原生 IDLE** 复现确认——不碰本项目任何代码，
原生 IDLE 同样报这条。它来自 `idlelib/window.py` 的窗口列表回调。
不影响使用，也不影响退出码。
