# 语言参考

pyPython 的语法**故意跟 Python 不一样**。核心区别：不用等号、不用 `print`、
没有冒号、没有分号。

> **本文所有例子都实际跑过。** 标「无输出」的是语法上跑得通但结果被丢弃的。

---

## 1. 赋值与输出

```
a「1」              赋值。用 「」 代替等号
a「a + 1」          重新赋值
$(a)               输出。用 $() 代替 print
```

- **变量自动创建**，不需要声明
- `「」` 可以跨行，像括号一样：

```
a「1 +
2」
$(a)               → 3 ⟨TRUE⟩ 0b11
```

## 2. 输出格式

输出**不是**裸值。数字要经过：

```
数字 → 真值密室判真假 → 手写二进制 → 全角装饰
```

所以：

```
$(1 + 1)           → 2 ⟨TRUE⟩ 0b10
$(42)              → 42 ⟨TRUE⟩ 0b101010
$("abc")           → "abc" ⟨TRUE⟩        字符串没有二进制
$([1, 2])          → [1 ⟨TRUE⟩ 0b1, 2 ⟨TRUE⟩ 0b10] ⟨TRUE⟩
$(-1)              → -1 ⟨HOPELESS⟩ 0b1
$(0.5)             → 0.5 ⟨LIMBO⟩ 0b0
$(未知)             → MAYBE ⟨MAYBE⟩
```

真值有**四档**：`FALSE` / `HOPELESS` / `LIMBO` / `TRUE`，只有最高档算真。
详见 [输出格式](输出格式)。

## 3. 运算符

### 比较

```
~                  等于（按 Shift）
·                  不等于（直接打，中圆点 U+00B7）
>  <               大于 / 小于
```

> ⚠️ `~` 和 `·` **在同一个键上**。打反了**不会报错**——两个都是合法运算符，
> 只会把意思算反。这是已知设计，见 [已知限制](已知限制)。

比较结果返回**真值格的档位序号**——**真是 `3`，假是 `0`**：

```
$(1 ~ 1)           → 3 ⟨TRUE⟩ 0b11      真的值是 3，不是 1！
$(1 ~ 2)           → 0 ⟨FALSE⟩ 0b0
$(1 · 2)           → 3 ⟨TRUE⟩ 0b11
$(3 > 2)           → 3 ⟨TRUE⟩ 0b11
```

> ⚠️ **跟 Python 不一样。** Python 里 `True == 1`，本语言里真 = `3`。
> 因为真值格有四档，程序直接拿**档位序号**当布尔值：
>
> ```
> FALSE=0    HOPELESS=1    LIMBO=2    TRUE=3
> ```
>
> `if` 判断不受影响（只有最高档算真），但你要拿比较结果去算数就得记住这点。
> 详见 [输出格式](输出格式)。

### 算术

```
+  -  *  /
```

**没有 `//`、`%`、`**`。**

`+` 也用于拼接，但**只能同类拼**：

```
"abc" + "def"      → "abcdef"
[1] + [2]          → [1, 2]
"a" + [1]          → 炑报错（不许混搭）
```

### 并排相乘

**并排即相乘**——两个操作数挨着写就是乘法：

```
x「(a + b) 2」       = (a+b)*2
x「(a + 1) 2 3」     = (a+1)*2*3    可以叠
$((2) 3)           → 6
```

**约束：只在括号语境里生效。** 下面这些都不行：

```
$(a + b 2)         炑报错：输出缺少收尾的 ')'
x「a 3」            炑报错：赋值缺少收尾的 '」'
```

为什么要有这个限制：不限制的话，`$(x) $(y)`（一行两输出）
会被误判成 `$(x)` 乘以 `$(y)`。

### 逻辑运算

```
a and b            用单词，不用 && || !
a or b
not a
```

- **会短路**：右边不一定算
- 返回的是**决定结果的那个操作数本身**（跟 Python 一样）：

```
$(1 and 2)         → 2 ⟨TRUE⟩ 0b10
$(0 or 5)          → 5 ⟨TRUE⟩ 0b101
$(not 0)           → 1 ⟨TRUE⟩ 0b1
```

- **三值感知**：碰到 `未知` 走 Kleene 真值表，详见 [三值逻辑](三值逻辑)

## 4. 注释

```
# 用井号，跟 Python 一样
```

**没有多行注释。**

## 5. 缩进与分块

```
if a ~ 1
    $(42)
else
    $(0)
```

- **没有冒号**
- **没有分号**
- 用**缩进**划块（跟 Python 一样）
- 块开启者只有：`if` / `else` / `while` / `for` / `def` / `class`

**一行可以放两条语句**（靠 `$()` 分割）：

```
$(1) $(2)          两个输出，不换行
```

## 6. 控制流

### if / else

```
if 条件
    ...
else
    ...
```

**约束：`else` 不能单独出现**，必须跟着 `if`。
**没有 `elif`**——用嵌套 `else` + `if` 代替。

### while

```
i「0」
while i < 3
    i「i + 1」
$(i)               → 3
```

**约束：有循环上限**（`MAX_DEPTH = 120` 圈）。超过就报错：

```
while 1
    $(1)           炑报错：循环超过 120 圈还没停
```

这是刻意的——**pyPython 故意不让你写死循环**。

### for

```
for v in [1, 2]
    $(v)
```

可以遍历**列表、字符串、字典**：

```
for c in "ab"                 → 逐字符
for k in {「"a"」: 1}          → 逐 key（不是键值对）
```

**不能遍历数字**（没有 `range()`，本语言不猜"循环 N 次"）。

### break / continue

```
for v in [1, 2, 3]
    if v ~ 2
        continue
    $(v)           → 1, 3

for v in [1, 2, 3]
    if v ~ 2
        break
    $(v)           → 1
```

**约束：只能在循环里用。** 写在循环外**解析期就报错**（不是运行期）。

```
break              炑报错（如果你不在循环里）
```

函数体里的 `break` **不会**打断调用方的循环——它自己就是非法的。

## 7. 函数

```
def 加(a, b)
    return a + b
$(加(1, 2))        → 3
```

- **参数没有默认值**
- **`return` 可以省略**，省略时返回 `0`
- 光写 `return`（不带表达式）也返回 `0`
- **可以递归**，但有深度上限（120 层）

```
def 阶乘(n)
    if n < 2
        return 1
    return n * 阶乘(n - 1)
$(阶乘(5))         → 120
```

### 作用域按 Python

函数里赋值默认建**局部**变量（所以递归天然正确）：

```
g「1」
def 只改局部()
    g「777」
只改局部()
$(g)               → 1  局部变量，外面没变
```

想改全局必须**显式声明**：

```
g「1」
def 改全局()
    全局 g「999」
改全局()
$(g)               → 999
```

## 8. 类

```
class 点
    def __init__(x, y)
        self.x「x」
        self.y「y」
    def 长度平方()
        return self.x * self.x + self.y * self.y

p「点(3, 4)」       直接调类名就是建对象
$(p.长度平方())      → 25
```

**约束（跟 Python 不一样）：`self` 不用写进参数表。**

```
def __init__(x, y)        写这样，不是 (self, x, y)
```

照 Python 习惯写 `def f(self, x)` **也行**——那个多余的 `self` 会被跳过，
真实的 `self` 永远指向调用者，不会被实参覆盖。

**没有继承、没有 `super`。**

## 9. 数据类型

### 数字

整数和浮点。**没有独立的布尔类型**（用 `1` / `0`）。

### 字符串

```
"abc"              只能用双引号
```

支持转义（`\n` `\t` `\"` `\\`）。

**不能用 `[]` 取字符**——会明确报错并告诉你怎么办：

```
s「"abc"」
$(s[0])            炑报错：字符串不能用 [] 取字符；
                        想按字符走请用 for c in "..."
```

### 列表

```
[1, [2], "x"]      可嵌套、可混类型
```

**下标**：按位置取，`-1` 是最后一个

```
xs「[10, 20, 30]」
$(xs[0])           → 10
$(xs[-1])          → 30
xs[1]「99」         下标也能赋值
$(xs[1])           → 99
```

可以嵌套：

```
m「[[1, 2], [3, 4]]」
$(m[0][1])         → 2
m[0][1]「55」       嵌套下标也能写
$(m[0][1])         → 55
```

**越界会报错**（不会静默返回 0）。

### 字典

```
d「{「"name"」: "pyPython", 「"n"」: 3}」
$(d["name"])
d["extra"]「[1, 2]」    新增一项
```

- **key 必须用 `「」` 包起来**，写 `{"name": ...}` 会报错
  （报错信息会直接告诉你怎么改）
- 冒号 `:` 是本语言**唯一的冒号用法**
- key 可以是数字或字符串；**列表不能当 key**（会报可读的错误）
- 取不存在的 key **报错**
- 遍历字典拿到的是 **key**

```
d「{}」                     空字典，不带 「」 也行
d「{「"a"」: 1, 「"b"」: 2}」
for k in d
    $(k)                   → "a", "b"
```

## 10. 三值逻辑

```
x「未知」           第三态字面量
$(x)               → MAYBE ⟨MAYBE⟩
```

`未知` 是**关键字**，不能被赋值覆盖（`未知「5」` 会报错）。

→ 完整说明见 [三值逻辑](三值逻辑)

## 12. 标识符规则

- 字母、数字、下划线，**不能数字开头**
- **支持中文**：`中文「42」` 完全合法
- **大小写不敏感**（内部会小写化）

## 13. 没有的功能

以下都**不支持**，写了会报错（不是静默失败）：

| 功能 | 报错信息 |
|---|---|
| 切片 `xs[0:2]` | 下标缺少收尾的 `']'` |
| 异常 `try/except` | 变量 `'try'` 之后期待 `'「'` |
| `import` | 变量 `'import'` 之后期待 `'「'` |
| `range()` | 名字 `'range'` 从未被 manifest 过 |
| 继承 `class B(A)` | 语句结尾期待换行，却遇到 `'('` |
| `lambda` | 赋值缺少收尾的 `'」'` |
| `while...else` | 语句必须以 变量名 / if / while / … 开头 |
| 字符串下标 | 字符串不能用 `[]` 取字符 |
| `//` `%` `**` | 运算符不支持 |
| `elif` | （用嵌套 else + if） |

→ 完整清单和替代方案见 [已知限制](已知限制)
