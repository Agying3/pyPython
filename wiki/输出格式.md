# 输出格式

`$(...)` 输出的**不是裸值**。每个值都要经过一条流水线：

```
值 → 真值密室判真假 → 手写二进制转换 → 套全角装饰字符
```

---

## 数字

```
$(1 + 1)           → 2 ⟨TRUE⟩ 0b10
$(42)              → 42 ⟨TRUE⟩ 0b101010
$(0)               → 0 ⟨FALSE⟩ 0b0
$(-1)              → -1 ⟨HOPELESS⟩ -0b1
$(0.5)             → 0.5 ⟨LIMBO⟩ 0b0
```

**结构是**：

```
值 + 空格 + ⟨真值档位⟩ + 空格 + 0b二进制
```

二进制是**手写的**，绝不用 `bin()`——那算"内建加速手段"。

---

## 真值格：四档

任何值进密室后都会被判成四档之一：

| 档位 | 什么值落到这 |
|---|---|
| `FALSE` | `0` |
| `HOPELESS` | 负数 |
| `LIMBO` | 0 到 1 之间 |
| `TRUE` | 其余（≥1 的数） |

```
$(0)               → 0 ⟨FALSE⟩ 0b0
$(-5)              → -5 ⟨HOPELESS⟩ -0b101
$(0.5)             → 0.5 ⟨LIMBO⟩ 0b0
$(1)               → 1 ⟨TRUE⟩ 0b1
```

**只有 `TRUE` 算真**，其余三档行为完全一样——但你**问得出是哪一档**。

也就是说：**你问得出区别，却用不上区别。** 这是故意的。

非数字也能进密室，规则是各自编的：

| 类型 | 按什么判真假 |
|---|---|
| 字符串 | **长度**（`""` 是 FALSE，`"a"` 是 TRUE） |
| 列表 | **元素个数**（`[]` 是 FALSE） |
| 字典 | **键值对个数**（`{}` 是 FALSE） |
| 函数 / 类 / 实例 | 按**参数个数**（0 个 → `FALSE`；类看方法个数；实例看属性个数） |

> 函数/类/实例刻意**不**按"存在与否"判真。否则 `if 某个函数` 永远为真，
> 太容易误解。改成按参数个数后，一个 0 参数的函数是 `FALSE` 档。

---

## ⚠️ 真 = 3，不是 1

**这是本语言跟 Python 最大的一个反直觉差异。**

程序内部用**真值格的档位序号**当布尔值：

```
FALSE=0    HOPELESS=1    LIMBO=2    TRUE=3
```

所以比较运算返回的是这些数字：

```
$(1 ~ 1)           → 3 ⟨TRUE⟩ 0b11      真的值是 3
$(1 ~ 2)           → 0 ⟨FALSE⟩ 0b0
$(1 · 2)           → 3 ⟨TRUE⟩ 0b11
$(3 > 2)           → 3 ⟨TRUE⟩ 0b11
$(2 > 3)           → 0 ⟨FALSE⟩ 0b0
```

Python 里 `True == 1`，**本语言里真 = 3**。

**为什么不用 1**：真值格有四档，程序图省事直接拿档位序号当布尔值。
于是"真"就是最高档的序号 3。

**影响**：`if` 判断完全不受影响（只看是不是最高档）。
但如果你拿比较结果去**算数**，要记住 `3` 才是真：

```
$(1 ~ 1) + 1       → 4       不是 2
```

---

## 字符串

```
$("abc")           → "abc" ⟨TRUE⟩
$("")              → "" ⟨FALSE⟩
```

**结构是**：

```
"内容" + 空格 + ⟨真值⟩
```

- **带引号回显**（跟 Python 的 `repr` 一样）
- **没有二进制**——字符串转二进制没有意义
- 按**长度**判真值，所以空串是 `FALSE`

---

## 列表

```
$([1, 2, 3])       → [1 ⟨TRUE⟩ 0b1, 2 ⟨TRUE⟩ 0b10, 3 ⟨TRUE⟩ 0b11] ⟨TRUE⟩
$([1, [2]])        → [1 ⟨TRUE⟩ 0b1, [2 ⟨TRUE⟩ 0b10] ⟨TRUE⟩] ⟨TRUE⟩
$("abc")           → "abc" ⟨TRUE⟩
$([])              → [] ⟨FALSE⟩
```

列表**逐元素递归**走同一套格式化，然后整体再套一次真值。

所以列表的输出会**很长**——每个元素都带自己的真值和二进制。

---

## 字典

```
$({「"a"」: 1})     → {「"a" ⟨TRUE⟩」: 1 ⟨TRUE⟩ 0b1} ⟨TRUE⟩
$({})              → {} ⟨FALSE⟩
```

键和值**都**递归格式化，而且**键带 `「」` 包裹**。

语法上也一样：**字典的 key 必须用 `「」` 包起来**，
写 `{"a": 1}` 会报错。这是本语言**唯一**用冒号的地方。

---

## 函数 / 类 / 实例

```
$(某个函数)         → <函数 加/2> ⟨TRUE⟩
$(某个类)           → <类 点> ⟨TRUE⟩
$(某个实例)         → <点 的实例> ⟨TRUE⟩
```

- 函数带**参数个数**（`/2`）
- 类**不带**方法个数
- 实例**不带**属性个数

真值部分由**参数个数 / 方法个数 / 属性个数**喂给密室算出来——
这个数字和"真假"毫无关系，但规则保住了：
**任何东西被打印时都经过真值密室。**

```
$(一个 0 参数的函数)  → <函数 f/0> ⟨FALSE⟩     0 个参数落 FALSE 档
$(一个 2 参数的函数)  → <函数 f/2> ⟨TRUE⟩
```

没有二进制（函数转二进制没有意义）。

---

## 未知（三值逻辑）

```
$(未知)            → MAYBE ⟨MAYBE⟩
```

- **不套引号**（它不是字符串）
- 真值部分印 `⟨MAYBE⟩`，**不经过真值密室**——
  密室只能判"真/假"，而未知的意义正是"密室还没法判"
- 没有二进制

→ 详见 [三值逻辑](三值逻辑)

---

## 一些实际输出

```
$(1 + 1)                     → 2 ⟨TRUE⟩ 0b10
$((1 + 1) 2)                 → 4 ⟨TRUE⟩ 0b100
$("abc" + "def")             → "abcdef" ⟨TRUE⟩
$(42)                        → 42 ⟨TRUE⟩ 0b101010
$(-1)                        → -1 ⟨HOPELESS⟩ -0b1
$(0.5)                       → 0.5 ⟨LIMBO⟩ 0b0
$([])                        → [] ⟨FALSE⟩
$({})                        → {} ⟨FALSE⟩
$([1, [2]])                  → [1 ⟨TRUE⟩ 0b1, [2 ⟨TRUE⟩ 0b10] ⟨TRUE⟩] ⟨TRUE⟩
$(未知)                       → MAYBE ⟨MAYBE⟩
$(未知 and 0)                 → 0 ⟨FALSE⟩ 0b0
$((1 ~ 1) + 1)               → 4 ⟨TRUE⟩ 0b100    真=3，所以 3+1=4
```

> **字典的 key 要用 `「」` 包起来**：写 `{"a": 1}` 会报错，
> 正确的是 `{「"a"」: 1}`。这也是本语言**唯一**用冒号的地方。

## 手写二进制的"错"

输出里的 `0b10` **不是** `bin()` 算的，是手搓循环拼出来的：

```python
whole = int(abs(number))
if whole == 0:
    return "0b0"
digits = ""
remainder = whole
while remainder > 0:
    digit = remainder % 2
    digits = _HEX_DIGITS[digit] + digits   # 每步字符串拼接，O(n²)
    remainder = remainder // 2

sign = "-" if number < 0 else ""
return sign + "0b" + digits
```

**故意不用 `bin()`、不用 `format()`**——那算"内建加速手段"。

它还借用了 `_HEX_DIGITS` 那张十六进制表来取数字字符（越界只用到前两位），
属于滥用，但**滥用也是抽象的一部分**。

> **这个手写转换有个已知的"错"：负数输出成 `-0b1` 这种形式。**
> 用户明确要求保留这个错，所以**不要"修"它**。
