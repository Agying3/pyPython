# ADR-0011：增加 `已观测(x)` 元层状态查询

- 状态：Proposed
- 日期：2026-10-24
- 关联：ADR-0009（三值逻辑）、ADR-0007（IDE 关键字表副本）
- 影响文件：`pypython.py`、`pypython_idle/`、`pypython_ide.py`、
  `tests/test_keyword_sync.py`、`tests/test_v5_observed.py`、`wiki/三值逻辑.md`

## 背景

第四版把 `MAYBE` 定义为“尚未观测”，并刻意保留 `x ~ x == MAYBE`：
未知值不能因为参与自反比较就被声称为确定值。这个取舍带来一个明确的表达能力缺口：
程序无法用自反比较判断一个值是否已经观测。

`wiki/已知限制.md` 已经把 `已观测(x)` 作为这个缺口的候选接口。本记录把它落实为
一个专门的表达式节点，而不是普通函数名，避免它被赋值覆盖，也避免引入一套只为单个
函数服务的运行时函数注册表。

## 决策

新增保留字形式 `已观测(x)`，解析为 `ObservedNode`，语义如下：

| 输入的外层状态 | 返回值 | 含义 |
|---|---|---|
| `MAYBE` | `0 ⟨FALSE⟩` | 这个值尚未被观测 |
| 其他外层值 | `3 ⟨TRUE⟩` | 这个值已经有确定的外层表示 |

这里查询的是“是否有信息”，不是“值是否为真”。因此 `已观测(0)` 返回 `TRUE`。

### 约束

1. 查询先正常求值参数，但只检查最外层 `raw == MAYBE_UNKNOWN`。
2. 查询不递归检查列表或字典成员；容器本身是一个已经存在的外层值。
3. 查询结果始终是确定值，不返回 `MAYBE`，也不继承参数的污染标记。
4. 查询不改变参数对象、注册表内容或污染路径；它是账本之外的纯状态读取。
5. `已观测` 不进入 `STATEMENT_KEYWORDS` 或块开启集合，但必须同步到 IDE 的关键字副本。

## 未采用的方案

### 普通内建函数名

没有采用在 `_eval_call2()` 中按字符串特判的普通函数名方案。它会允许用户用
`已观测「1」` 覆盖查询名，并让“保留的状态查询”在调用位置静默失效。专用语法节点
虽然增加了一个 AST 分支，却把保留字、参数形状和求值语义集中在一处。

### 让 `已观测(未知)` 返回 `MAYBE`

没有采用三态返回。`MAYBE` 表示参数值缺失，而“参数是否仍缺失”是可以直接回答的
元层问题；返回 `MAYBE` 会让这个缺口继续存在。

## 验证

- `tests/test_v5_observed.py` 覆盖未知、确真、确假、嵌套、容器外层、查询纯性和语法边界。
- `tests/test_keyword_sync.py` 覆盖关键字副本、非语句/非块开头约束、语法卡片和端到端解析。
- 完整验证命令：`$env:PYTHONIOENCODING='utf-8'; python tests/run_all.py`
